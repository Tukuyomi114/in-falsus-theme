# In Falsus 主题插件

把《In Falsus》的界面UI套到 DeepSeek Harness 上，在全新的世界进行名为“心域探潜”的深度求索。

## 安装

在 DSH 的插件管理器里「安装插件」填一个 spec，底层由 pnpm 解析。支持的形式：

| 来源 | spec 示例 |
|---|---|
| GitHub | `github:Tukuyomi114/in-falsus-theme`，或整条 `https://github.com/Tukuyomi114/in-falsus-theme` |
| npm | 包名，例如 `dsh-theme-in-falsus` |
| 本地目录（开发用） | `link:C:/绝对/路径/in-falsus-theme` |

装完需要**完全退出 DSH 再打开**：宿主半区（`index.js`）只在进程启动时加载。

本地开发时也可以手工建软链，效果等同 `link:`：

```
~/.dsh/profiles/desktop/node_modules/@local/in-falsus  ->  本目录
```

换机器时把本目录链接（或复制）到同一位置即可。`package.json` 的 `dsh.bundle.patch` 指向 `cordis.patch.yml`，里面只有一行把本插件加进组合。

## 改哪里、怎么生效

| 改动 | 生效方式 |
|---|---|
| `client.js`（样式、品牌标、文案替换、开场播放） | 保存即热更新，不用重启 |
| `index.js`（Host：首帧调色板、影片路由） | **完全退出 DSH 再打开** |
| `package.json` / 新增文件 | 完全重启；换包名可绕元数据缓存 |

改完先 `node --check <文件>`：**语法错会让热更新静默失效**，页面保持旧样式且没有任何报错提示。

## 覆盖范围（深色）

- 调色板令牌 + 页面底色渐变
- 侧栏：品牌行（棱镜标 30px + 官方字标）、会话行（青色刻度/选中态）、面板图标（切角板 + 粒子带）、新会话框（青色刻度板）、底部头像行（银色刻度板）
- 聊天区：用户气泡（四角切角 + 青色立体刻度）、工具调用行（边框与洗色一起向右淡出 + 左上斜线收口 + 银色刻度）、步骤汇总行（无边框银灰渐变带 + 等宽斜体）、回合分隔线（竖杠尺线）
- 输入框：四角切角、外壳 + 内缩面双层描边、青色刻度、点阵内表面
- 面板页（插件/自动化任务/上下文洞察）与设置弹窗：上暗下亮渐变 + 青蓝点阵 + 方形网格（四周留白）+ 静态小方块
- 开场影片：启动时全屏播放一次

## 开场影片

`media/intro.mp4` — 5 秒、1600×900、无声。

每次应用启动是带有开场特效，会播放一次影片（`sessionStorage` 记标记，刷新页面不重放），播完淡出交给界面，`Esc` 可跳过。要换片：替换同名 mp4，或改 `client.js` 里 `playBoot` 的路径。

## 已知限制

- **浅色模式未适配**：所有视觉规则都按深色写死，浅色下会不协调。计划另做一套红白配色的第二主题。
- 选择器依赖 CSS Module 哈希（`.hKdVjq_`、`.AnXs9G_`、`.GRgSLq_` 等），DSH 升级后可能整体失效，需要按新哈希更新。
- 两处文案替换靠 DOM 观察者（`探索未至之境` → `Exspēs, cold wings fold around us`，`深度求索中` → `心域探潜中`），上游改文案即失效。
- 桌面壳不认 `tapIndex`，首帧调色板只能走 `webserver/index-inject` 的结构化注入行。
- 影片路由不支持 Range，播放器不能拖动进度，完整播放不受影响。

## 文件

```
index.js            Host 半区：首帧调色板注入 + 影片路由
client.js           客户端半区：样式、棱镜标、文案替换、开场播放
media/intro.mp4     开场影片
cordis.patch.yml    组合补丁（一行 include）
locale/{en,zh}.json 插件管理器里的标题与描述
icon.svg            插件图标
```
